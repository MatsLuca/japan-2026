# 🇯🇵 Japan 2026 — Crew Wiki

Eine vereinte Master-Page (Single-Page-App) für unsere Japan-Reise (22.07.–18.08.2026).

**Live:** https://matsluca.github.io/japan-2026/

## Views (Hash-Router, kein Reload)
- `#/home` — Hub (Countdown, Crew, Index)
- `#/uebersicht` — Dashboard: Crew, Route, Budget, Unterkünfte
- `#/tagesplan` — 28 Tage mit Foto-Hintergründen
- `#/ergebnisse` — Auswertung der Crew-Umfrage (6/6)

Die Stimmungs-Umfrage liegt weiterhin extern: https://matsluca.github.io/japan-umfrage/

## Aufbau
- `index.html` — die komplette App (~98 KB), Design „Sumi-Ink Editorial"
- `assets/img/` — externalisierte Fotos (dedupliziert)

Keine exakten Adressen enthalten.
